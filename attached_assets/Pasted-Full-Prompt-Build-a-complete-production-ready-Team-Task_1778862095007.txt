🌐 Railway Deployment Guide
Step 1 — Push Code to GitHub

Create GitHub repository:

frontend
backend

Push complete code.

Step 2 — MongoDB Atlas Setup
Create MongoDB Atlas cluster
Create database user
Whitelist IP: 0.0.0.0/0
Copy MongoDB connection string

Example:

MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/taskmanager
Step 3 — Deploy Backend on Railway
Backend Environment Variables
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
CLIENT_URL=https://yourfrontendurl.com
NODE_ENV=production
Railway Steps
Go to Railway
Create new project
Connect GitHub repo
Select backend folder
Add environment variables
Deploy

Backend must return live API URL.

Example:

https://team-task-manager-api.up.railway.app
Step 4 — Deploy Frontend

Use Railway or Vercel.

Frontend Environment Variables
VITE_API_URL=https://yourbackendurl.com/api
Build Command
npm run build
Output Directory
dist
